# WireCamera

Mac 原生摄像头预览工具。双击「应用程序」中的 **WireCamera.app**（安装路径：`/Applications/WireCamera.app`），或打开项目目录中的同名应用，首次运行在系统提示中允许摄像头访问，即可查看实时画面。

- 自动优先选择外接 USB 摄像头，可在右上角切换设备。
- 支持镜像、调整窗口大小、全屏（⌃⌘F），按原始比例显示画面。
- 支持拔插设备自动重连；⌘R 重新连接。
- 底部显示实际画面分辨率与帧率。
- 支持 MOV 视频录制，可选择录入摄像头自带的声音；录制时显示计时。
- 支持声音监听和音量调节；监听与录入声音独立。
- 音视频仅在本机预览或保存，不上传。仅在监听或录入声音时请求麦克风权限。

如果没有画面，请检查 USB 连接、关闭其他使用摄像头的应用后点击“重试”。如果拒绝过授权，在“系统设置 → 隐私与安全性 → 摄像头”中开启“WireCamera”，然后重新打开应用。

## 录制

1. 连接摄像头并等待画面出现。需要声音时勾选「录入声音」；未找到摄像头对应的音频输入时，此选项不可用。
2. 点击「开始录制」，选择 MOV 文件的保存位置。取消保存对话框不会开始录制。
3. 点击「停止录制」，等待显示「已保存」，再点击「显示文件」在 Finder 中定位视频。

录制使用摄像头画面，镜像状态与开始录制时的预览一致。录制期间禁止切换摄像头、镜像和声音来源。选中「录入声音」时，首次运行需要允许系统麦克风权限；此权限用于摄像头自带的声音，不会自动切换到 Mac 或 iPhone 麦克风。

「监听声音」只控制本机播放，不决定视频是否带声音；建议使用耳机避免回声。声音匹配使用系统的关联设备信息，或根据 USB 位置、厂商、产品和序列号明确关联。无法匹配时禁用声音选项。

录制中的文件先写入所选文件夹的临时文件，完成后才替换目标文件。保存失败会显示临时文件的位置。录制中关闭窗口或退出应用，会先完成当前文件的写入；不要强制结束进程。设备断开或磁盘空间不足时，应用会尝试结束录制并提示结果；意外断电或设备错误不保证临时文件可恢复。

## 从源码构建

适用于 Apple Silicon Mac，macOS 14 及以上。构建需要 Apple Command Line Tools；运行已构建的应用不需要开发工具或其他依赖。

```sh
zsh scripts/build.sh
open "WireCamera.app"
```

应用使用 AppKit 与 AVFoundation，无第三方依赖。构建产物与缓存都在项目内；使用本机临时签名，供当前 Mac 直接运行。跨机器分发需另行开发者签名及公证。

只读设备诊断（不请求权限、不打开预览）：

```sh
"WireCamera.app/Contents/MacOS/WireCamera" --diagnose
```

## 录制端到端验证

连接带声音输入的 USB 摄像头，并安装 ffmpeg（含 ffprobe）后运行：

```sh
zsh scripts/build.sh
zsh Tests/recording-e2e.sh
```

测试会保存真实摄像头的图像和声音样片。样片、轨道信息、解码日志和报告均位于 `.build/recording-e2e/`，不会上传。测试通过真实应用控件录制无声、带声音及退出时保存的 MOV，再用 ffprobe 检查音视频轨和时长，用 ffmpeg 完整解码。失败场景和人工验收项见 [录制验收](Tests/recording-scenarios.md)。
