# 画面比例验收

实现前确定的失败场景：摄像头没有 16:9 格式、设备锁定失败、设置格式后被会话预设覆盖、添加声音输入后格式改变、切换摄像头后模式失效、切换过程中收到旧帧、录制期间更改格式、快速重复选择、拔出设备、录制文件与预览尺寸不一致、预览层仍按旧比例显示而数据帧已切换为新比例。

预览验证同时检查数据帧尺寸和预览层实际视频区域的宽高比，文件验证同时检查像素比例与显示比例。

测试前必须退出所有 WireCamera 实例。重复启动应用应激活已有窗口，不应新增摄像头会话；多个实例可能争用同一 USB 摄像头的原生格式。

`Tests/probe-uvc-controls.c` 只读检查当前 USB 摄像头的 UVC 摄像头终端控制位，不执行硬件设置。当前 VID 1133、PID 2085 的设备未声明绝对/相对调焦、自动对焦、绝对/相对变焦控制。

连接此摄像头后运行 `zsh Tests/picture-mode-e2e.sh`，依次通过实际应用控件选择 4:3、16:9、4:3，等待对应尺寸的预览帧，录制带声音的样片，检查录制时模式选择被锁定。ffprobe 检查文件分别为 1280 × 960、1280 × 720、1280 × 960，ffmpeg 完整解码。

可重复执行的 JSON 报告、日志和真实音视频样片保存在 `.build/picture-mode-e2e/`，不上传。无宽屏设备、USB 物理拔插和设备占用需要人工验证。
