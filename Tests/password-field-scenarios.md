# Wi-Fi 密码输入框验证

实现前确定的故障场景：聚焦密码框出现系统密码或自动填充入口；选择该入口后面板不响应；安全字段与共享编辑器的用途配置不一致；移焦、重新聚焦后恢复自动补全；引号、破折号或空格替换改变密码；显示原始密码；关闭密码面板后主窗口失去响应。

验证使用 AppKit 的真实窗口、sheet、安全文本字段和字段编辑器，输入固定测试文本，检查遮罩、用途、自动补全状态及密码字节保留，执行移焦、关闭、重新打开和退出。独立辅助应用不访问蓝牙，不写摄像头配置，不修改系统自动填充设置。

可重复运行 `zsh Tests/password-field-e2e.sh`。JSON 报告与界面 PNG 保存到 `.build/password-field-e2e/`。自动测试通过公开 AppKit 编辑器和控件发送输入；另通过原生 UI 交互复核密码框没有钥匙串入口、面板与窗口能够关闭。
