# 流式回放与画面变化检测验收

实现前确定的失败场景：

- 限速网络下，播放器仅获取头部、索引及目标时间附近数据即可出画面，不等待一分钟录像完整下载，不生成整段 MOV 缓存。
- 支持索引位于文件末尾的旧录像、任意时间跳转、连续拖动、取消旧请求与片段接续；已取消请求不能覆盖新的播放位置。
- 所有元数据、字节范围、播放租约与续期请求均携带认证信息并校验证书指纹；错误证书、令牌过期、范围响应有误、文件不存在及网络中断必须明确失败。
- 播放器只保留有限的前向缓冲；切换摄像头、日期或断开连接后释放读取与播放租约。后台暂停后不持续下载，回到前台能重新读取。
- 清理规则不能在分块请求间隙删除当前回放录像；租约释放或到期后仍可按保留规则清理。旧 iPhone 的原始录像接口继续兼容。
- 画面变化检测不依赖人形。移动物体和模糊遮挡可标记；静止画面、轻微编码噪点、均匀曝光变化不误标为运动。
- 人物和画面变化分别存储、显示和筛选；旧索引可后台补算变化，新字段缺失不影响旧录像读取。识别取消、文件被清理和重启不能生成幽灵索引。

`zsh Tests/streaming-e2e.sh` 使用真实 AVPlayer、生产范围加载器、带音轨 MOV 和限速 HTTPS 服务，记录出画面耗时、实际读取字节、跳转结果及解码帧，产物位于 `.build/streaming-e2e/`。测试不连接实际摄像头。

`zsh Tests/motion-e2e.sh` 通过真实应用索引静止、曝光变化、移动和模糊遮挡视频，验证人物 / 变化区分及重启恢复，保留报告、索引、时间轴和事件列表截图。

`zsh Tests/index-backlog-e2e.sh` 在 600 段旧录像等待补算的情况下验证主线程启动响应、优先完成最近录像的分析、活动筛选和重启恢复；使用独立目录，不连接正在录制的摄像头。
