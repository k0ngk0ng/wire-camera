# 摄像头模块连接验收

实现前确定的失败场景：蓝牙权限拒绝、蓝牙关闭、扫描超时、同名或多个模块、模块退出配网、连接断开、服务或特征缺失、Wi-Fi 列表不可用、SSID 为空或超过 32 字节、密码超过 63 字节、重复提交、通知订阅失败、写入失败、响应丢包或乱序、响应格式错误、配网超时、Wi-Fi 密码错误、连接窗口关闭。

配网仅操作明确选择的模块。扫描不会连接其他蓝牙设备；选择模块后验证真实服务与特征。密码使用安全输入框，不写入日志、报告或偏好设置。关闭窗口停止扫描并释放连接。

运行 `zsh Tests/module-connection-e2e.sh`，通过主窗口入口打开连接窗口，使用真实蓝牙发现模块并检查 GATT，验证 Wi-Fi 表单、密码遮罩与输入校验。该测试不发送 Wi-Fi 配置。JSON 报告、界面截图及日志保存在 `.build/module-connection-e2e/`，可重复执行。

真实配网与视频取流单独验证：由用户在连接窗口输入网络信息，确认模块响应及可访问的视频数据后，才能报告已接入画面。

重新打开应用时不能依赖启动参数中保存的蓝牙 UUID 或设备 ID。已配网模块应通过局域网自动发现；未配网模块通过蓝牙发现。蓝牙名称以当前广播中可识别的名称为准，缓存名称为空、过期或稍后才收到名称时仍须识别；反复扫描、关闭后重开和选中同一模块不能丢失设备或保留旧回调。扫描期间区分等待权限、蓝牙关闭、扫描进行中和已结束，不能静默退出。网络扫描超时或取消必须有界，不能卡住发送套接字。
