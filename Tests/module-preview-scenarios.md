# 摄像头模块实时预览验收

实现前确定的失败场景：已配网模块不再广播蓝牙、模块地址经网络转换、只回复二进制发现报文、局域网认证失败、控制响应与视频帧交错、视频分片不完整、视频解密失败、格式尚不支持、缺少关键帧或参数集、解码失败、开始取流但没有实际画面、USB 旧帧覆盖模块画面、切换回 USB 后模块旧帧覆盖预览、连接中断和应用退出。

运行 `WIRECAMERA_MODULE_DEVICE_ID=设备ID zsh Tests/module-preview-e2e.sh`。模块须已配网，Mac 与模块网络互通。测试不修改无线配置、不使用厂商账号，通过实际应用窗口执行发现、认证和取流，等待真实视频帧显示，并保存实际解码画面、JSON 报告和日志。产物位于 `.build/module-preview-e2e/`，不会作为发布附件。

只有真实模块视频帧经过系统解码并进入预览层，才能报告预览通过。局域网认证成功和收到压缩字节均不能替代画面验证。

预览稳定后再通过实际「重试」动作重新连接同一模块，设备选项必须保留，不能切换到 USB。重试后再次持续显示 12 秒才通过。
