# Mac 设置与录像保留验收

实现前确定的失败场景与边界：

- 旧配置缺少保留天数字段时继续永久保留；保存设置不改变密码、证书、端口或已配对手机的协议。
- 永久保留不清理文件；1–3650 天有效，负数、非整数和超出范围不能保存。仅清理结束时间不晚于截止时间的已完成录像及其人物索引。
- 正在录制的临时文件、跨越截止时间的录像、近期或未来录像、无关文件和指向目录外的符号链接均保留。
- Mac 当前回放的录像与正在通过 HTTPS 读取的录像暂缓清理；释放后下一次清理可回收，其他回放和录制不受影响。
- 到期录像正在进行人物检测时取消任务，回调不能重新生成已删除的索引。
- 删除失败时保留可重试的记录并显示错误；可删除的其他录像继续清理。残留的到期索引可在后续清理中回收。
- 修改保留策略取消旧清理任务，永久保留立即阻止后续自动删除；启动、周期检查和保存设置均可触发清理。
- 提供「立即清理」，按当前已保存的保留时间运行；保存更短的保留时间立即在后台执行清理，不等待定时周期。未保存的改动不能用于手动清理，清理进行中避免重复触发。
- 连接窗口的开启、关闭、端口修改、密码显示和输入校验分别生效；保存保留天数不重启手机服务或断开正在读取的连接。
- 二维码清晰且可用 macOS Vision 解码，内容仍为旧 iPhone 版支持的配对 URL；关闭状态不显示密码二维码，字段和按钮无重叠、越界。
- 通过真实 Mac 设置控件保存、退出、重启后仍保留所选天数与连接配置；旧访问令牌仍可访问同一证书的服务。

`zsh Tests/settings-e2e.sh` 在项目内生成带音轨的录像和历史索引，启动隔离的真实 Mac 应用，通过设置控件与 HTTPS 客户端执行上述操作。报告、窗口截图和日志保存在 `.build/settings-e2e/`，不操作日常录像，不需要连接 iPhone。
