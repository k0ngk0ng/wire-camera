# 录制验收

实现前确定的场景：

- 录制无声视频；重复录制；录入摄像头自带音频；监听与录入声音独立。
- 复现带声音录制返回 AVFoundation -11800 / -12780；带声音的样片必须包含可完整解码的音轨，音视频时长差小于 1 秒。
- 取消保存对话框不产生文件；录制中禁止切换摄像头和镜像；停止后恢复预览。
- 已有目标文件保留至新录制完成，保存失败保留临时文件并显示位置。
- 摄像头或声音设备拔出、权限拒绝、输出不可写、磁盘空间不足、设备占用：明确提示，不悄悄使用其他麦克风。
- 开始后立即停止；重复点击；启动录制失败；停止期间退出：不得重复保存或提前退出。
- 正在录制时关闭窗口或退出：等待写入完成后退出。

运行 `zsh Tests/recording-e2e.sh`。需要连接 USB 摄像头，允许相机和麦克风权限，并安装 ffmpeg（包含 ffprobe）。测试会在 `.build/recording-e2e/` 保存真实摄像头样片、JSON 报告与解码日志，可重复执行。测试期间摄像头周围的图像和声音会保存在这些样片中，不上传。

自动验收使用真实应用控件和真实捕获会话，先保持监听开启连续录制无声、带声音样片，再关闭监听录制带声音的退出保存样片；使用 ffprobe 检查时长及音视频轨，使用 ffmpeg 完整解码。保存对话框取消、USB 物理拔插、磁盘耗尽仍需人工验收。
