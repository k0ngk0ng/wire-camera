# 实时与回放验收

实现前确定的失败场景与边界：

- USB 与 Wi-Fi 使用相同的录制入口；界面没有「录入声音」选项。没有摄像头声音、权限拒绝或音频中断时，不得静默生成无声录像，也不得使用 Mac 麦克风替代。
- 点击录制自动保存；录制中切换到回放仍持续录制；停止或分段完成后自动出现在当前摄像头、对应日期的回放列表。
- 界面显示本次连续录制的累计时长，分段保存期间不归零、不切换为状态文字；停止后保留总时长，再次开始录制从零计时。实时画面显示本机当前日期与时间，每秒更新，回放时隐藏。
- 单击视频画面切换播放 / 暂停；拖动不触发切换，底部控件和时间轴不会被画面点击逻辑重复处理。人物图例和实际标记使用相同的实心橙色圆点。
- 录制来源与实时预览来源独立。录制 A 时切换到 B、B 断线、重连或切回 A 均不能停止或污染 A 的录制；跨分段仍保存到 A 名下，每台摄像头的录制按钮、累计计时、分段状态和错误独立；停止当前摄像头不影响其他摄像头。USB 录制来源的格式不能在录制时修改。
- 支持两台及以上摄像头同时带声音录制。A、B 的图像、音轨和元数据不能串流；一台断线或停止后，其他摄像头继续保存新片段。重新开启其中一台只重置它自己的计时，退出应用等待全部片段保存完成。
- 回放画面没有系统悬浮控制器，播放、暂停、进度、音量、倍速和全屏控件固定在视频底部；通过实际控件验证暂停、恢复、静音、音量及倍速。
- 连续录制每 60 秒保存一个片段；录制来源的画面比例在录制期间禁用，实时预览可切换其他摄像头。退出应用应等待当前片段保存。
- 回放摄像头从录像元数据建立列表，已离线、未发现或已移除的设备仍可选择。切换回放摄像头仅筛选本地录像，不重新连接设备、不改变实时来源、不停止当前录制；后台新片段保存时保留回放摄像头与日期选择。重启后不进行网络扫描也可选择离线摄像头并播放。
- 回放支持选择日期、点击全天时间轴定位文件并连续播放、缩放和平移、点击人物事件跳转；空日期、未录制、正在生成索引和识别失败分别显示真实状态。
- 人物识别只在本机执行，识别到的相邻时间合并；无人画面不能凭空生成人物事件。事件跳转位置必须位于对应录像范围内。
- 重启后恢复录像和人物索引；忽略未完成的临时视频和损坏的元数据，单个损坏文件不能阻止其他录像显示。
- 显式指定 `--record-camera` 时，仅连接指定的已保存 Wi-Fi 摄像头；收到图像与声音后才自动开始录制，不请求 USB 摄像头或 Mac 麦克风，不重复启动录制。
- 保存目录不可写、磁盘不足、视频或音频断流、立刻停止、重复停止、退出保存与索引同时进行：给出可恢复的错误，保留可用文件。
- 播放历史录像时，实时摄像头仍持续工作；返回实时后画面正常。切换录像或返回实时时暂停原来的播放器。

运行 `zsh Tests/library-e2e.sh`。测试通过本机 TCP 模拟模块发送真实 JPEG 与 PCM/G.711 音频数据，经应用真实录制按钮、回放入口和人物事件按钮完成验收。脚本保存 MOV、轨道信息、完整解码日志、截图及 JSON 报告到 `.build/library-e2e/`，并重启应用核对恢复结果。模拟模块通过不代表 HA10 实机声音协议已验证。

实机另行核对 USB 和 HA10 的音源、连续分段、设备拔插、权限拒绝及磁盘耗尽；不得把模拟模块结果描述为实机结果。
