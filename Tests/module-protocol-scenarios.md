# 摄像头模块报文验证

本文件和测试向量先于协议实现建立。

失败场景：SSID 为空、UTF-8 编码超过 32 字节或含控制字符；非空密码少于 8 字节、超过 63 字节或含控制字符；验证码超过单字节长度限制；编码后的报文超过旧版 SDK 可安全分包的 255 字节；空片段、总数为零、序号越界、长度不符、非末片段不足 17 字节、总数中途改变和重复序号内容冲突；加密模式不符、密文长度错误、报文截断、解密失败、缺失或不一致的 PKCS#7 尾填充、数据格式错误、缺少成功状态、设备拒绝、缺少设备标识。

成功场景：固定时间戳下的 ASCII、UTF-8 SSID 和开放网络配置与独立向量一致；分包按顺序、乱序和含相同重复包重组得到相同内容；失败后能够重新组包；模拟成功响应提取设备标识和第二个字符串。

向量来源：对官方安装包 `libipcuser.so` 的静态指令分析。AES-CBC 密文同时通过 Python cryptography 和系统 OpenSSL 生成并交叉比对。向量尚未经原 SDK 执行或真实模块配网确认，不能将本测试通过等同于实际设备已联网。

运行：先编译 `Sources/CameraModuleProtocol.swift` 和 `Tests/module-protocol-check.swift`，再从项目根目录运行所得程序。程序输出 `.build/module-protocol-check/report.json`。
